# BOM & Architecture Strategy: "Cost-Optimized Multi-Tier"

**版本/Version**：v0.6 (Cost-Optimized Edition)

**日期/Date**：2026-01-19

**范围/Scope**：经济型多档 BOM + 10K 单规模化降成本 + 风险评估

**核心策略/Core Strategy**：
1. **极简版 (WiFi-Only)**：**RV1106 (0.5 TOPS) + WiFi** —— COGS **$38**，售价 $99-129，极致性价比
2. **经济版 (4G)**：**RV1106 (0.5 TOPS) + 4G** —— COGS **$48**，售价 $149-179，主推走量款
3. **标准版**：**RV1109 (1.2 TOPS) + 4G** —— COGS **$52**，售价 $179-199，基础 AI 增强
4. **中配版**：**RV1126 (2.0 TOPS) + 4G + 双摄** —— COGS **$62**，售价 $199-249，进阶 AI
5. **高配版**：**RK3576 (6.0 TOPS) + 4G + 双摄** —— COGS **$88**，售价 $299-349，旗舰级边缘 AI

**优化重点**：
- ✅ **SoC 降档**：RV1106 采用 PoP 封装（SoC + RAM 一体），省 PCB 成本
- ✅ **摄像头降档**：GC2053 (2MP/1080p)，中国 IPC 市场主流 Sensor
- ✅ **单摄替代双摄**：去掉 Low Cam，简化 BOM
- ✅ **屏幕优化**：320x960 RGB 电梯屏（标准品，无 NRE）
- ✅ **规模化采购**：10K 单 MOQ，降幅 20-30%

- ✅ **条形比例** (1:3)，满足"长条形"需求，适合车载后视镜/中控台

## 3. 核心计算平台差异化 BOM (Compute Platform)

### 3.1 极简版/经济版：RV1106 + PoP 架构

**RV1106 芯片规格**：
- **制程**：28nm
- **CPU**：1× Cortex-A7 @ 1.0GHz（单核）
- **NPU**：**0.5 TOPS** (Int8) —— 支持人脸检测、车牌识别、简单 ADAS
- **ISP**：支持 2MP (1920x1080)，内置 3A
- **视频编码**：H.265/H.264 @ 1080p@25fps
- **内存**：**PoP 封装** (Package on Package) —— SoC + DDR2 RAM 叠在一起
- **接口**：
    - 1× MIPI-CSI (2-Lane)
    - 1× RGB666/MIPI-DSI (可选)
    - USB 2.0 Host + OTG
- **Rockchip 定位**：低成本 IPC (IP Camera)、门铃、入门行车记录仪

**核心板 BOM (RV1106 PoP, 10K 单)**：

| 子系统 | 料号/规格 | 10K 单价 (USD) | 说明 |
| :--- | :--- | :--- | :--- |
| **SoC + RAM** | RV1106 + 512MB DDR2 PoP | **$6.80** | 封装一体，省 PCB 走线 |
| **Flash** | 8GB eMMC 5.1 (Foresee) | **$2.30** | 满足 1080p 录制 + 系统 |
| **PMIC** | RK809 (电源管理) | **$0.90** | RV1106 专用 |
| **晶振/时钟** | 24MHz 晶振 | **$0.25** | ±30ppm 可接受 |
| **电源滤波电容** | 陶瓷电容 + 低 ESR 电解 | **$0.35** | 简化电源设计 |
| **PCB** | **4-Layer** (全通孔) | **$2.00** | PoP 不需要 DDR 走线，降为 4 层 |
| **散热** | 导热石墨片 | **$0.60** | 功耗 < 1W，被动散热 |
| **小料** | 二极管/保护器件 | **$0.25** | USB/CSI 保护 |
| **核心板小计** | | **$13.45** | **比 RV1126 省 $3.05** |

**PoP 封装优势**：
- ✅ **省 PCB 面积** —— 无需 DDR 走线，PCB 从 6 层降为 4 层（省 $0.40）
- ✅ **省物料** —— 不需要外置 RAM 颗粒的阻抗匹配电阻/电容
- ✅ **简化设计** —— 不需要 DDR 信号完整性 (SI) 仿真
